# TgNewsRelayBot

## Описание

TgNewsRelayBot — это мощный Telegram-бот, который автоматически парсит новости с заданных сайтов и репостит их в указанные Telegram-каналы. Благодаря боту вы можете всегда быть уверены, что ваш канал наполнен свежими и актуальными новостями без необходимости ручного поиска и публикации.

## Основные возможности

- **Автоматический парсинг новостей** с нескольких источников по заданному интервалу.
- **Репост свежих новостей** непосредственно в ваши Telegram-каналы.
- **Управление источниками новостей** через команды бота: добавление и удаление сайтов для парсинга.
- **Управление каналами публикации**: добавление и удаление каналов, куда бот будет отправлять новости.
- **Отслеживание истории публикаций**, чтобы избежать повторного размещения одних и тех же новостей.
- **Настройка интервала парсинга** для гибкого контроля публикаций.
- **Поддержка прокси** для обхода ограничений доступа к источникам.
- **Команды для просмотра статуса бота, списков сайтов и последних публикаций** прямо в Telegram.
- **Интуитивно понятное меню управления** с клавиатурой и кнопками для удобного взаимодействия.
- **Безопасность и контроль** — бот ограничивает доступ к управлению только указанным администраторским ID.

## Почему стоит использовать TgNewsRelayBot?

- Экономия времени — бот самостоятельно ищет и репостит новости без вашего участия.
- Актуальный контент — новости обновляются регулярно, что поддерживает интерес подписчиков.
- Простота настройки и управления через Telegram.
- Надежность и стабильность работы благодаря использованию асинхронных запросов и хранению истории.
